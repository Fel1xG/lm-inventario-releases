## Cómo instalar

1. Abre el enlace de arriba **desde el celular** y descarga `lm-inventario.apk`.
2. Abre el archivo. Si Android lo pide, permite **Instalar apps desconocidas**.
3. Toca **Instalar** e inicia sesión con tu cuenta.
4. Acepta las notificaciones: la app avisa de cada versión nueva y se actualiza sola con un toque.

¿Teléfono antiguo de 32 bits? Usa [`lm-inventario-arm32.apk`](https://github.com/Fel1xG/lm-inventario-releases/releases/latest/download/lm-inventario-arm32.apk).

Las novedades de cada versión están en [Releases](https://github.com/Fel1xG/lm-inventario-releases/releases).
